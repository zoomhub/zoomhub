# ZoomHub

**ZoomHub is alive and actively developed at [zoomhub.net](https://zoomhub.net).**

This repository holds the last open-source version of ZoomHub, from
February 2026. It is archived and no longer updated. ZoomHub has been
developed privately since then, and newer versions are not open source.

The code here stays available under the [MIT license](./LICENSE).

## Questions and support

This repository no longer takes issues or pull requests. For questions
or support, get in touch through [zoomhub.net](https://zoomhub.net).

## About

ZoomHub is a cloud service for viewing arbitrarily high-resolution
zoomable images. It took over from the former Microsoft service
**[zoom.it]** as a full, from-scratch rewrite by the same developers who
built the original.
